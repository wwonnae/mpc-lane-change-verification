# VII. 결론

2025년 12월 제출 졸업논문의 설계를 요구사항 명세로 삼아 제어기를 새로 구현하고, 실행 전에 고정한 기준으로 다시 검증하였다.

**재현·검증 결과**

1. **제출본 설계의 MPC는 E2 paper 조건(초기 헤딩 0)에서 제약을 만족하는 조향각을 계산하였다** — 단, 제출본 설정값 가운데 서로 호환되지
   않는 두 곳을 고친 뒤이다([개정]: 복귀 임계값, 초기 위치 절단). E2에서 {{c:249}}, 횡방향 위치 {{c:250}}의 만족률을 보였다(허용오차 §19).
   초기 헤딩 오차가 있는 강건성 조건(S6)에서는 위치 제약 위반 사례가 관찰되었다.
2. **그러나 제출본 설계는 충돌을 완전히 막지 못하였다.** 제출본의 "충돌 0회" 대신, 기하학적 충돌 판정을 도입한 결과 E2 paper에서
   충돌 {{n:e2_paper_baseline}}, 회피 성공 {{n:e2_paper_base_success}}였다. 분석한 충돌 사례의 원인은 장애물을 모르는 비용함수였고, 개선판(v2)은 E2 전 조건에서 충돌이 관측되지 않았다(합산 {{n:e2_coll_pool_base}} → {{n:e2_coll_pool_v2}}, {{n:e2_coll_pool_p}}).
3. **제출본 입력 정의의 Student는 폐루프 주행에 실패하였다.** 제출본이 향후 과제로 남긴 폐루프 검증을 수행한 결과, 개루프 오차는 작았지만
   paper 성공 {{n:i4_cl_paper_succ}}였다. 원인은 입력에 헤딩이 없어 교사의 조향을 원리적으로 결정할 수 없다는 명세 결함이었고, 이를
   계산으로 증명해 세 번째 [개정]으로 고쳤다.
4. **헤딩을 더한 Student(S10)는 미사용 평가 데이터에서 에피소드별 결과(성공·충돌·타임아웃)가 교사와 모두 같았다(시뮬레이션, E3)** — paper {{n:e3_paper_S10_succ}}, S3 {{n:e3_S3_S10_succ}},
   충돌 0, 교사와 결과가 다른 에피소드 0. 조향 개루프 오차는 {{c:251}}, 추론 시간 p99는 교사 대비 PyTorch {{n:ratio_p99_pt}}, ONNX
   {{n:ratio_p99_ox}} 빠르다(실행 범위). 제출본 수치({{s:251}}, {{s:255}})와는 교사·입력·데이터·측정 방법이 달라 직접 비교하지 않는다.

**한계**

1. **시뮬레이션에 한정된다.** 단일 정지 장애물(및 강건성 변형), 운동학 모델, 이상화된 센서 변환이며 실제 RC카·실차 검증은 하지 않았다.
   Student는 센서 노이즈·제어 지연(S4·S5) 조건에서 평가하지 않았다.
2. **신경망은 제약을 구조적으로 보장하지 못하고 후처리에 의존한다.** S10도 원출력이 ±25°를 넘는 경우가 있었다(E3 원출력 초과율 / 최대 /
   분포 이탈: paper {{n:e3_iv_S10_paper}}, S3 {{n:e3_iv_S10_S3}}). 제약 만족의 보장은 MPC에만 해당한다.
3. **Student는 조향만 대신한다.** FSM·종방향 속도·후처리는 규칙 기반이며, Student를 만들려면 교사 MPC가 필요하다.
4. **학습 절차의 차이**: 제출본의 데이터 증강(입력 노이즈·상태별 밸런싱)을 적용하지 않았다(V장 3절).
5. **재현하지 못한 제출본 수치**: 계산 시간, 학습 표본 수, 일부 표의 정의·출처는 근거 파일이 없어 새 측정값으로 대체하였다(부록 A).
6. **계산 시간은 노트북 한 대에서만 측정하였다.** 공식 호스트(x86 노트북, 부록 B)에서만 공식 조건으로 쟀으며, 임베디드 보드에서의 시간은
   측정하지 않았다. 임베디드 적용 여지는 이 측정에서의 상대 비교로만 판단한다.
7. **개선판의 설계 한계**: 초기 헤딩 오차·지연이 큰 조건에서 KEEP_L1 전이 직후 위치 제약을 소폭 넘는 경우가 개발 데이터에서 관찰되었다.

**향후 연구**

1. 실제 RC카에서의 폐루프 검증과, Student의 노이즈·지연 조건 평가.
2. 출력 제약을 신경망 구조에 넣어(예: 유계 활성화) 후처리 의존을 줄이는 방법.
3. 신경망을 먼저 쓰고 판정 규칙이 위험을 감지하면 MPC로 넘기는 하이브리드 구조.
4. 제출본이 제안한 DAgger류 반복 학습 — 이 보고서에서는 입력 정정만으로 E3 분포 이탈이 교사와 같은 크기로 줄어 적용하지 않았지만, 다른 시나리오로
   확장할 때 필요할 수 있다.
