## 3. 학습 데이터와 교사 제어 명령 분석

제출본 VI장 3절은 교사가 만든 학습 데이터의 통계와 품질을 한 절에서 다뤘다. 이 보고서에서는 두 대상이 다르므로 나눠서 쓴다.
(1)은 Student 학습 데이터(개발 데이터 D, 교사 improved v2), (2)~(4)는 제출본 설계의 MPC(baseline v1.1)가 E2에서 실제로 낸 제어 명령의
통계이다.
