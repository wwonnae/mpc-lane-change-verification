# 서문

이 문서는 **2025년 12월 제출 졸업논문 「MPC 기반 모방학습을 이용한 자율주행 차선변경 시스템」을 명세로 삼아 제어기를 재구현하고 검증한
기술보고서**이다. 학위 심사 제출본이 아니며, 제출본 자체는 수정하지 않고 그대로 보존한다.

**어떻게 만들었나.** 제출본을 요구사항 명세로 읽어 {{n:n_req}}개의 요구사항 ID로 나누고, 제어기와 시뮬레이터를 처음부터 다시 구현하였다(기존
코드는 비교용으로만 읽음). 측정 기준·seed·판정 규칙은 실행 전에 고정했고, 개발용 데이터와 평가용 데이터를 나눠 평가 데이터로는 아무것도
조정하지 않았다. **이 문서의 모든 결과 수치는 새로 측정한 값**이며, 제출본 수치는 "제출본" 열이나 문장에서 비교용으로만 인용한다.

**재현 과정에서 확인된 사실.** 제출본에는 서술이 모호하거나 빠진 곳이 있었고, 이는 결정표에 근거한 최소 가정으로 채웠다. 또한 서로 호환되지
않거나 원리적으로 불가능한 설정이 {{n:n_revision_items}}건 확인되어 고쳤다([개정]). 세 건 모두 같은 기준 — **계산·분석으로 불가능이 증명된
명세만 수정** — 을 따랐다.

1. 복귀 완료 임계값: 전이 직후의 위치 제약과 호환되지 않음(IV장 1절).
2. 초기 횡방향 위치 분포: 절단이 없으면 시작부터 위치 제약을 지킬 수 없는 경우가 생김(III장 2절).
3. Student 입력: 헤딩이 없어 교사 MPC를 원리적으로 모방할 수 없음(VI장 7절).

이 밖에 근거 파일을 찾지 못한 수치(계산 시간, 학습 표본 수)와 정의가 맞지 않는 표가 있어, 새 측정값으로 대체하고 부록 A에 사실을 기록하였다.

**제출본이 한계로 남긴 검증.** 제출본은 "Student 정책의 실제 주행 성능이 검증되지 않았다"를 첫째 한계로 적었다. 이 보고서는 그중 시뮬레이션 폐루프
검증을 수행하였다. 제출본 입력 그대로의 Student는 실패했고(paper 성공 {{n:i4_cl_paper_succ}}), 헤딩을 입력에 더한 Student는 한 번도 쓰지 않은
평가 데이터에서 에피소드별 성공·충돌·타임아웃 결과가 교사 MPC와 모두 같았다(시뮬레이션)(paper 성공 {{n:e3_paper_S10_succ}}, 충돌 {{n:e3_paper_S10_coll}}).

**읽는 방법.** 장 구성은 제출본을 따르고, 제출본에 없던 강건성 검증(VI장 5절), 개선판(VI장 6절), Student 폐루프 검증(VI장 7절)을 더하였다. 모든 표·그림
캡션에는 `[데이터 | 호스트 | 버전 | 커밋]` 조건 태그가 있으며 코드 정의는 부록 B에, 제출본의 모든 수치와 이 보고서 값의 대응은 부록 A에 있다.
본문의 수치는 `docs/revision/REVISION_NUMBERS.csv`의 행에서 자동으로 채워지고, 조립 도구가 본문 수치와 표의 일치를 검사한다(부록 C).
