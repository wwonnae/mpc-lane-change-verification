# V. 모방학습 기반 정책 학습

이 장은 Student(신경망 정책)의 데이터·구조·학습 설정을 정리한다. 결과는 VI장 4절(제출본 입력 그대로의 Student)과 VI장 7절(입력을
정정한 Student)에 있다.

## 1. 학습 데이터 생성

### (1) 교사와 데이터 범위

제출본은 "FSM + MPC 시스템"을 교사로 100개 에피소드에서 19,129개 샘플을 모았다고 서술한다. 재현 과정에서 이 샘플 수를 만든 실행
기록은 저장소에서 찾지 못했고, 가장 가까운 저장 데이터와도 개수가 달랐다(부록 A). 그래서 이 보고서는 데이터를 새로 만들었다.

- **교사**: 개선판 MPC(improved v2, VI장 6절). 개선 단계의 최종 MPC를 교사로 삼았다. 제출본 설계를 그대로 옮긴 baseline MPC와의
  차이는 VI장 6절에 있다.
- **범위**: 개발용 데이터 D(부록 B)만 사용한다 — paper 시나리오와 S3 격자에서 {{c:48}}. 평가 데이터(E2·E3)는 학습에 쓰지 않는다.
- **표본**: MPC가 실제로 호출된 스텝만 표본으로 삼는다. Student는 MPC가 내던 조향만 대신하고, 라인추종·SAFE_STOP 스텝은 규칙이 그대로
  처리하기 때문이다(VI장 7절). 에피소드당 평균 표본은 {{c:49}}이다.

**표 5-1. 학습 데이터(제출본 대비).** [데이터: D | 호스트: H1 | 버전: 교사 v2 MPC | 커밋: C5]

| 항목 | 제출본 | 이 보고서 |
|---|---|---|
| 에피소드 수 | {{s:48}} | {{c:48}} |
| 에피소드당 평균 표본 | {{s:49}} | {{c:49}} |
| 총 표본 수 | {{s:50}} | {{c:50}} |
| KEEP_L2 / EVADE_L / KEEP_L1 / RETURN_TO_L2 | (표 10 참고) | {{n:i4_n_KEEP_L2}} / {{n:i4_n_EVADE_L}} / {{n:i4_n_KEEP_L1}} / {{n:i4_n_RETURN_TO_L2}} |

KEEP_L1 표본이 적은 것은 이 상태에서 라인이 보이면 라인추종을 쓰기 때문이다(라인을 놓친 짧은 구간에서만 MPC가 호출됨). 개발 seed를
늘려 재생성해 보았지만 모든 상태가 같은 비율로 늘어 이 비율은 바뀌지 않았고(구조적 원인), Student가 실제로 쓰이는 분포와 같으므로
사전에 정한 범위를 그대로 썼다.

### (2) 입력과 출력

- **입력(제출본 9차원)**: 속도 v, ey(라인 감지 시 ey_line, 미감지 시 y − 목표선), front_gap, left_clear, FSM 상태 one-hot(5).
- **입력 정정 [개정]**: 헤딩 ψ를 더한 {{n:S10_dim}}차원(Student S10). 제출본 MPC의 출력은 ψ의 함수인데 9차원 입력에는 ψ가 없어, 같은 입력에
  서로 다른 정답이 대응한다. 증명과 실험은 VI장 7절에 있다. 비교용으로 직전 조향 δ_prev까지 더한 {{n:S11_dim}}차원(S11, [발전])도
  학습하였다.
- **출력**: 조향각 δ(MPC 원출력)와 목표 속도 v_target(규칙 기반 종방향 출력). MPC가 호출되는 스텝에는 SAFE_STOP이 없어 v_target은 사실상
  상수이므로, 평가는 δ 중심으로 하고 v_target 오차는 참고로만 쓴다.

## 3. 학습 알고리즘

**표 5. 학습 설정(제출본 대비).** [데이터: 설정값 | 호스트: H1 | 버전: Student 9입력 · S10 · S11 | 커밋: C5]

| 항목 | 제출본 | 이 보고서 | 태그 |
|---|---|---|---|
| Optimizer | {{s:56}} | {{c:56}} | [정합] |
| Learning rate | {{s:57}} | {{c:57}} | [정합] |
| Batch size | {{s:58}} | {{c:58}} | [정합] |
| Epochs | {{s:59}} | {{c:59}} 전부 실행, 검증 손실 최저 epoch의 가중치 채택 | [해석] |
| Train/Val | {{s:60}} | {{c:60}}, 에피소드 단위 계층 분할 | [정합]+[공백] |
| 손실 | {{s:55}} | {{c:55}}, 가중 없음 | [정합] |
| 입력 노이즈 증강 | {{s:61}} | {{c:61}} | 미적용 |
| 상태별 밸런싱 | {{s:62}} | {{c:62}} | 미적용 |

- **분할**: 같은 에피소드의 연속 스텝은 강하게 상관돼 있어 스텝 단위로 나누면 검증 손실이 낙관적으로 나온다. 에피소드 단위로 나누되
  상태별 스텝 비율이 학습·검증에서 같도록 계층 분할했고, 분할 seed는 하나로 고정해 결과를 보고 다시 나누지 않았다(학습/검증
  {{n:i4_train_val}}).
- **정규화 통계**는 학습 분할만으로 계산하였다(검증 데이터가 전처리에 섞이지 않도록).
- **안정화 장치 [공백]**: 기울기 노름 절단 {{n:grad_clip}}, 검증 손실이 개선되지 않으면 학습률을 줄임(계수 / 대기 epoch = {{n:plateau}}). 학습 seed는 고정.
- **증강 미적용**: 제출본 V장 3절(3)의 입력 노이즈 N(0, 0.01²)와 상태별 밸런싱(복제·제거)은 이 보고서의 Student에 적용하지 않았다.
  밸런싱은 복제한 표본이 학습·검증 양쪽에 걸쳐 검증 손실을 낙관적으로 왜곡할 수 있어 설계 단계에서 제외했고, 입력 노이즈는 설계에서
  다루지 않아 빠졌다. 평가가 끝난 모델을 바꾸지 않기 위해 재학습하지 않았으며, 한계로 VII장에 적는다.
