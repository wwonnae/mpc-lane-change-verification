    OS/런타임 지터로 보입니다(추정, 근거: 연산 그래프가 입력과 무관하게 동일). 따라서 정확한 주장은
    "Student는 **연산량**이 입력과 무관하고, 시간 분포의 p99/p50 비가 MPC보다 작다"이며, "CV가
    일정하다"는 주장은 이번 수치로 뒷받침되지 않습니다.
- ONNX 변환 검증: 1,000건에서 δ 최대 차이 9.5e-6° (fp32 수치오차 수준).

### 6-1. 결론 요약 (수치는 paper / S3)

1. **주원인 — Student 입력으로는 필요한 상태를 관측할 수 없음(확인됨)**: v2 MPC의 δ는 헤딩 ψ와 직전 조향
   δ_prev에 의존하지만, REQ-STU-02의 9차원 입력에는 둘 다 없습니다.
   - 학습 데이터 자체에서도 Student 입력을 센서 분해능 격자(ey 0.01m, front_gap 0.05m, left_clear,
     상태)로 묶으면 **교사 δ 분산의 33.4%가 같은 칸 안의 차이**(칸 내 표준편차 4.8°)로, 입력만으로는
     설명되지 않습니다(KEEP_L1 58%, KEEP_L2 42%, EVADE_L 36%, RETURN_TO_L2 33%).
   - 폐루프 중 오차(Student − 같은 입력 v2)는 ψ와 강하게 상관: r = 0.61/0.57(EVADE_L), 0.65/0.63(KEEP_L1),
     0.54/0.55(RETURN_TO_L2).
   - 개루프 MAE 2.48°(§3)가 작았던 것은 v2 자신의 궤적에서는 ψ가 (ey, 상태)와 함께 움직여 간접적으로
     추정되기 때문입니다(추정, 근거: 위 상관과 아래 ψ 분포 차이). Student가 조향하면 이 관계가 깨집니다.
2. **분포 이동 — 확인됨, 크게**: 학습 split 통계 기준 |z|>3 비율이 학습 데이터 자신 0.88% → 폐루프
   **13.5% / 15.6%**. 상태별 조건부 기준(상태별 평균·표준편차)으로는 1.0% → **30.0% / 32.4%**.
   - 상태별(조건부 |z|>3): RETURN_TO_L2 47.3% / 49.6%, KEEP_L1 72.6% / 78.9%, EVADE_L 6.1% / 5.9%,
     KEEP_L2 5.9% / 0%. RETURN_TO_L2는 입력이 그 상태 학습 범위(min–max) 밖인 비율도 52% / 54%.
   - 시간대별(조건부): 0–2s 2.4% / 3.6% → 2–4s 22% / 30% → **6–8s 68% / 74%** → 8–10s 41% / 40%.
   - 관측 불가능한 변수에서도 이동이 큽니다: RETURN_TO_L2의 평균 |ψ|는 v2 자기 궤적 9.6° / 9.7° 대비
     Student 궤적 **28.6° / 31.0°**(약 3배). 이 이동은 입력 z-score에 잡히지 않습니다(ψ가 입력이 아님).
3. **오차 누적 — 확인되지만 부차적**: |Student δ − v2 δ| MAE는 **처음 2초부터 이미 7.9° / 8.1°**
   (개루프 2.48°의 3배 이상, 입력 이동이 2–4%로 작은 구간). 이후 시간대별 7.6–9.4°로 완만. 에피소드 내
   전반→후반 평균 8.30→9.28° / 8.26→9.49°, 후반이 더 큰 에피소드 84% / 78%. 즉 오차는 **시작부터 크고**
   진행하며 약 1° 더 커집니다. 폐루프 전체 MAE는 8.6° / 8.6°(상태별 KEEP_L2 6.1°, EVADE_L 8.3°, KEEP_L1
   7.1°, RETURN_TO_L2 9.2°, paper 기준).
4. **실패 기전(대표 에피소드, 스텝별 표·그림)**:
   - seed 201(충돌): EVADE_L에서 Student가 v2보다 +6–11° 더 좌로 조향(ψ 34°까지 증가) → KEEP_L1에서
     y=0.45(차로 상한)까지 과진입 → 반대로 −25° clip 구간을 거쳐 ψ −41°로 급복귀 중 차체 모서리가
     장애물과 겹침(step 93).
   - seed 202·204(타임아웃): RETURN_TO_L2에서 ψ가 −30°일 때 v2는 +10–12°로 되받아 치는데 Student는
     +1–3°(입력이 ey 하나로 사실상 축약되어 같은 값 −18.48°, −15.72°, 2.56° 등이 반복) → y가 −0.43m까지
     과복귀 후 다시 반대로 흔들리며 종료까지 복귀 조건을 만족하지 못함.

1. **신경망은 제약을 구조적으로 보장하지 못하고 후처리 clip에 의존합니다.** S10도 폐루프 호출의 0.80%(paper) / 1.23%(S3)에서
