## 2. 핵심 주장별 결론

1. **[최우선] MPC(OSQP, 2-state)로 제약을 만족하는 조향각** — v2는 원출력 자체가 |δ|≤25°를 QP 허용오차 안에서 만족(eval3 원출력
   초과 0%). baseline도 제약 만족, 단 S3 경계 조건에서 실패 81/900 → 3단계 v2가 0/900으로 개선.
2. **[최우선] 종방향은 규칙 기반** — 모든 버전(Student 포함)에서 유지. MPC·Student 모두 속도를 결정하지 않음.
3. **[보조] 신경망 임베디드 적용 여지** — 논문 입력 명세(9차원)로는 논문 MPC를 원리적으로 모방할 수 없음이 계산으로 증명됨(SETTINGS_DECISION
   §20). ψ를 추가한 S10은 시뮬레이션 폐루프에서 v2 MPC와 같은 결과를 내고 ONNX 추론 p99가 v2 MPC의 약 1/50. 단 제약은 보장하지 못하고
   clip에 의존(원출력 초과 0.8–1.2%, 최대 26.0°), FSM·종방향·후처리는 규칙 기반, 검증은 시뮬레이션 한정(`RESULT_I4.md` §11).
